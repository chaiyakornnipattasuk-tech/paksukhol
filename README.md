# PAKSUKHOL · ภักดิ์สุคนธ์

Website for **หนึ่ง นคร สกล 💙**, a digital creator from Sakon Nakhon, and her shirt line **เสื้อ นคร สกล**.

ผ้าครามนครสกลหนึ่งเดียว — Sakon Nakhon, re-woven in gold, indigo & faith.

## Files

- `index.html` — the whole site (one page)
- `paksukhol-blanc.webp`, `paksukhol-noir.webp` — her artworks (white and black editions)
- `images/` — photos used on the page
